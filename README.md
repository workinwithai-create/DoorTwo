# DoorTwo

Two-bar live section-entry door desk for bedroom producers and AI-music finishers.

Suno and loop-based DAWs hard-cut chorus into verse 2 (or any section into the next) with no door. Session players write two live bars that open the next pocket: bass lean, kit thin, nylon reply, piano door, brass answer, violin hold, stop then go, hush then spark, octave push, pedal open.

DoorTwo seats live FluidR3 chairs on that cut, plays chorus vs door vs next, and exports a punch list.

Live samples only — FluidR3 acoustic grand, upright bass, nylon guitar, trumpet, violin, and an acoustic kit from the PreEight sample CDN. No oscillators. Audio never leaves the tab.

## Distinct from yesterday and the rest of the line

| Tool | Job |
| --- | --- |
| LiftTwo | Two bars of climb *into* the first hook |
| PickupTwo | Two-bar live pickup so the chorus does not slam in cold |
| CueFour | Four-bar pick-up / count-in for unfinished sections |
| TurnFour | Four-bar section *turnaround* (hand-off inside a section) |
| TagFour | Four-bar last-line *tag* that ends the record |
| PreEight | Eight bars *before* the hook |
| AfterHook | Eight bars *after* the hook as a floor / vamp |
| BridgeFour / BridgeEight | The missing middle |
| **DoorTwo** | Two bars that *open* the next section so the previous one does not dump cold |

Yesterday’s family ships handled lifts, tags, pickups, and turnarounds. DoorTwo is the missing *entry door* after a chorus (or any section) into whatever comes next.

## How to use

1. Open the desk. Chairs load from the PreEight sample CDN.
2. Pick a groove (Amber / Porch / Fold / Harbor).
3. Stamp a door recipe.
4. Hear A: chorus loop. Hear B: full form. Hear 8: door + next only.
5. Copy the punch list. Drop the idea on bars 9–10 of your session.
